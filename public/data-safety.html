Data Safety & Permissions

Transparent overview of data handling, local persistence, and Android permissions matching the Google Play Console Data Safety declaration for Arrow Escape.

1. Data Collection & Sharing Overview

Data Category Status Implementation Details
Personal Info (Name, Email, Phone) Not Collected No sign-up, login, or account profile exists in the game.
Location (Precise or Coarse GPS) Not Collected No location APIs or GPS permissions are requested.
Photos, Videos & Microphone Audio Not Collected File and microphone access are explicitly disabled.
Game Progress & Preferences Local Only currentLevel, hints, dailyStreak, and audio settings are saved locally on-device via AsyncStorage / localStorage.
Device / Advertising IDs Ad SDK Only (When Live) Not collected in simulated preview builds. Once production AdMob ads are linked, Google AdMob handles Advertising ID for ad delivery and fraud prevention.

2. Security & Transport Practices

Arrow Escape enforces strict portrait gameplay and secure local storage without external analytics trackers:

HTTPS Only: Capacitor builds enforce androidScheme: https and allowMixedContent: false.

Data Deletion on Request: Players can wipe all locally saved levels, hints, and streaks anytime using Settings → Reset Saved Progress or via Android system app storage settings.
